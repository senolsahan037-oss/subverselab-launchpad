## What SubverseLab presets are

Audio Effect Racks for Ableton Live. Each one is a chain of Live's own devices with
eight macros mapped across it and several saved macro variations, so one rack gives
you more than one result.

**No Max for Live. No third-party plugins.** Every device in every rack ships with
Live, which is why the download works on your machine and not only on ours.

## The racks

### Percussion Repeat

EQ Eight → Compressor → Saturator → Beat Repeat → Redux → Reverb → Utility

8 macros, 4 saved macro variations.
Built in Ableton Live 12.4.5.

Repeat sets how long the stutter is, Grid sets how it is divided. Grain and Type
change what the repeat is made of. Redux takes resolution away, Reverb puts the
space back. Each saved variation is a different answer to the same bar.

### Drum Buss

EQ Eight → Glue Compressor → Saturator → Utility

8 macros, 3 saved macro variations.
Built in Ableton Live 12.4.3.

## Installing

1. Download the `.adg`.
2. Drop it into your User Library, or anywhere in Live's browser.
3. Drag it onto an audio track.

Live version matters: a rack saved in Ableton Live 12.4.5 will not open in an older
Live. That is Live's rule, not ours.
