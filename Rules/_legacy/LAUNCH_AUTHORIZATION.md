# Rule
The SubverseLab Launchpad is the only authorized production gateway. A product may not leave the Launchpad for deployment until every mandatory requirement has been successfully completed.

## Reason
The Launchpad does not create products. The Launchpad certifies products. Only certified products may enter production. This guarantees that all products meet the same quality standards and avoids deployment of incomplete, unverified, or guessing-based metadata.

## Expected Behavior
- Validation checks all mandatory assets (Valid manifest, Valid version, Valid guide, Cover image, Preview asset, Actions definition, Content type, Required product assets, Validation report, QA checklist, Rule compliance, Security validation, Deployment validation, Metadata synchronization validation).
- If every mandatory validation succeeds, output `LAUNCH AUTHORIZED`.
- Continue to Deployment, Metadata Sync, and Publish.

## Forbidden Behavior
- Bypassing these rules by any AI agent, developer, automation, deployment script, or administrator.
- Launching with placeholders, inferred metadata, guessed actions, autogenerated product descriptions, or autogenerated guides.
- Continuing to Deployment, Metadata Sync, Preview, or Publish if validation output is `LAUNCH DENIED`.
